# Ostatni cykl

Psychologiczna gra science fiction o wyborach — wersja przeglądarkowa.

Statek badawczy. Obca maszyna, uruchomiona bez zgody dowódcy. Porucznik, który przeżył — ale nie jest już tym samym człowiekiem. Trzy osoby chcą od maszyny czegoś innego. Ty masz zdecydować, komu oddać ostatni cykl.

Najlepiej grać na telefonie. 5 zakończeń, gra zapisuje się sama.

Autorka: Aleksandra Stelmach · przy użyciu Claude Opus 5.5
